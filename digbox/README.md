# DIGBOX 製品サイト

LENCOISサイト内の `/digbox/` に統合しました。今後の更新はこのリポジトリで行います。
元の `digbox-web` リポジトリは変更せず、過去の履歴として残しています。
Git履歴の結合や入れ子の `.git`、submoduleはありません。

## 構成

- `index.html`: 製品紹介
- `guide.html`: 使い方
- `faq.html`: よくある質問
- `privacy.html`: プライバシーポリシー
- `support.html`: サポート
- `css/`、`js/main.js`、`images/`、`screenshots/`: 製品専用の表示・素材

元サイトのMarkdown管理データにある最新の文章をHTMLへ反映済みです。
閲覧時のMarkdown取得・文章差し替え処理は使いません。
文章はHTMLを直接更新するか、Markdown原稿からAIで対象HTMLに反映し、差分と表示を確認してください。
元サイトの設計メモ、Git管理情報、エディタ設定、画像加工スクリプトは取り込んでいません。
書体はmacOSなどのシステムフォントを使い、外部Google Fontsの読み込みを廃止しました。
メニュー開閉は維持し、本文はJavaScriptなしでも表示します。

## 公開前の確認

App Storeのリンクは元サイト同様に未設定です。
サポートのメールアドレス、アプリの仕様とプライバシーの説明は公開前に実際の内容と照合してください。

## 正式ロゴ

`images/brand/` のSVGをヘッダー・フッター・ファビコンに使用します。
正式色の指定は `#0096e0`（SVG内部の色は支給データの `#0097E0` を維持）。
本文は濃いグレー、リンク・ボタンは可読性を考慮した濃い青とし、白と淡い水色を基調にしています。
